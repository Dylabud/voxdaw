* **[2026-04-29] Phase 8 — Piano Roll HUD:** Added a vertical 2-octave (C3–B4) piano keyboard to the left edge of the viewport that lights up in real time to reflect the active chord. `PianoRoll` is a `forwardRef` component exposing a single imperative `setNotes(noteNames[])` method via `useImperativeHandle` — zero React state, zero re-renders. Key layout computed once at module scope: 14 white keys (B4→C3) as a flex column, 10 black keys as an absolute overlay with `topPct = ((whiteIndexAbove) + 0.7) / 14 × 100` and height `0.6/14 × 100 ≈ 4.29%`. Internal `keyMapRef` (Map) enables O(1) element lookup; `activeSetRef` (Set) enables diff-based class toggling so frames with no chord change produce zero DOM writes. `normalizeNote()` added to `dsp.js` maps Tone.js flat names (Bb/Eb/Ab/Db/Gb) to sharps (A#/D#/G#/C#/F#). `updateParams` computes `activeNoteNames` using `Tone.Frequency(hz).toNote()` after chord gate logic and calls `hud.pianoRoll.current.setNotes()`; a `pitchHandFound` flag clears the keyboard when the pitch hand leaves frame. `stopAudio` clears the keyboard before disposal. Piano styled as `position:absolute, left:0, width:44px`, with a `mask-image` gradient fade on the right edge to integrate with the camera feed. Active keys: `#5DCAA5` (full on black, 0.82 opacity on white) with 40ms CSS transition.

* **[2026-04-29] Phase 7 — The Instrument Rack:** Added a second parallel voice set — 4× `Tone.FMSynth` strings voices — alongside the existing 4× `Tone.Synth` analog voices. Both sets connect to the shared Filter → Vibrato → Reverb → Volume effects chain; Tone.js sums them at the filter input. Strings preset: `harmonicity: 3.5`, `modulationIndex: 10`, sawtooth carrier, sine modulator, `envelope.attack: 0.3s` / `release: 0.8s`, `modulationEnvelope.attack: 0.5s` (delayed modulation bloom mimics bowing). Active set tracked via `activeVoicesRef` (plain ref, zero re-renders); `currentRootRef` stores last-known root so `setInstrument` can snap incoming voices to the correct frequency. Switching: old set fades to VOICE_MUTE over 100ms, new set root fades to VOICE_DB — chord harmonics follow on next rAF frame. `stopAudio` dispose timeout extended to 1200ms for strings 0.8s release. `setOscType` restricted to analog voices only. Added instrument `<select>` as the first dropdown in `Controls.jsx`; oscillator dropdown conditionally hidden when strings is active. `INSTRUMENTS` constant defined inline in Controls. `setInstrument` exported from `useAudioEngine`; wired through `App.js` → `onInstrumentChange` prop.
